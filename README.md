# Dk Gestor Unidade

Monte um aplicativo com o nome Dk Gestor Unidade.

Utilize o documento da API enviado para embasar o projeto.

Sendo um dashboard de consulta.

Na primeira aba Alunos, deve ser possível consultar os dados gerais dos alunos de todas as informações disponíveis na API.

Na segunda aba valores devem ser relacionadas informações referentes a valores recebidos e contas pagas.

E uma terceira aba de Dados Gerais, onde deve ser informado os valores recebidos, despesas, quantidade de matrículas, quantidade de cancelamentos, quantidade de alunos, tendo o filtro por data.

A consulta é por unidade, sendo possível colocar um único token.

Pensado como um dashboard para o diretor consultar as informações, uma interface simples que seja de fácil visualização e entendimento, pensando na experiência do usuário, tanto na visualização pelo desktop como por um celular.

O token da unidade deve ficar salvo no navegador do dispositivo utilizado, dispensando o login e mantendo a segurança.
